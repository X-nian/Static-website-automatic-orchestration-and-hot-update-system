# 历史采集与自动更新

采集前结合 [state-and-versions.md](state-and-versions.md) 的字段和提交顺序。这里规定操作流程，不代表某个平台接口已经安装或可用。

## 先探测实际入口

复用档案已有来源，按当前可用情况选择已连接接口、用户现成批量导出、公开页面或已登录浏览器。优先低操作成本的可用渠道，不能为了遵循固定优先级让用户额外导出已有可读数据。

使用本地导出时记录文件版本/摘要值和导出覆盖时间，后续可检查该文件是否变化；“文件已读完”不代表线上账号已同步到现在。没有线上入口时，不能用本地读取时间冒充线上内容的新鲜度。

首次逐平台做最小探测：读取账号身份，获取可枚举的内容列表，再打开至少一篇/一期详情，检查正文及相关媒体实际覆盖。保存工具或页面路径、身份、观察时间和真实能力。后续重用路径；出现登录变化或平台布局变化时重新探测。

### 小红书

1. 从用户提供的主页或笔记入口核对作者及账号标识；短链接用实际跳转结果定位。
2. 在可读主页列表中分页或滚动发现笔记，区分置顶与时间顺序。记录每条的稳定ID、作者和详情链接；主页卡片不算正文。
3. 打开详情获取展开后的标题、正文、标签、时间及可见指标。正文折叠或只看到摘要时标为partial。
4. 图文笔记分别记录图片是否可读、图中文字是否提取及轮播覆盖；缺图不能推断整套视觉风格。视频按实际字幕或可访问音频处理。
5. 身份不匹配不入本人档案；登录墙、验证码或访问限制单独记录，停止对该入口的无效重复操作。

### 微信公众号

1. 通过账号名称、可确认的账号标识及文章署名核对来源；一个文章链接只能证明该篇可读，不能证明可以枚举全部历史。
2. 如有用户已授权的后台、接口或历史文章目录，记录实际可枚举范围及分页方式。没有列表入口时可从可访问文章链接或批量导出学习，标记历史覆盖不完整。
3. 打开文章正文，区分正文、导航、推荐阅读及页尾模板，保留对作者风格有意义的段落与排版。
4. 图片文字、署名、发布时间、标题和正文分别记完整度；没有阅读量或后台统计权限时不填指标。
5. 不把个人微信聊天接口、公众号文章读取和后台发布权限混为同一种能力。

### B站

1. 从空间、视频或用户提供的列表核对UP主及账号ID，分别记录投稿、专栏或其他实际内容类型。
2. 获取可访问列表及视频详情，保留稳定视频ID，多分P内容记录分P标识。标题、简介、标签与字幕分开存。
3. 优先取得实际可访问字幕，保存来源、语言、覆盖片段及时间戳。无字幕且能合法取得音频时才使用已可用的转写工具；只取得简介时不能报告“视频已转写”。
4. 封面和时间点画面有观察证据才用于视觉分析。AI转写错误、只有片段或非原语言翻译都应降低相应证据置信度。
5. 记录每个视频的字幕/画面能力，不将一个视频验证成功泛化为全账号全部视频可用。

### 其他平台

沿用“身份 → 列表 → 详情 → 媒体 → 完整度 → 持久化”的流程，记录实际能力，不编造平台API地址、编辑字段或排序规则。

## 一次生成前如何刷新

默认配置来自profile：新鲜度24小时、首次30条/平台、旧文回查最近10条或最近30天内的条目（取并集，上限30条）、单次最多100条新发现内容/平台。用户指定范围或更改这些配置时以用户为准；达到单次上限要保存分页并标出尚未完成，不宣称全量。

来源满足以下任一条件时进入刷新：首次、成功检查超过新鲜度、用户要求最新、存在到期重试、存在中断分页、旧文回查到期。即使历史新鲜，已到期的失败条目也不能被跳过。对同一来源单次只执行一个合并刷新计划。

刷新包含三组工作：

1. **新发现**：按真实列表顺序分页，使用主键去重；不能比较平台ID字符串大小，也不能把置顶项当最新水位。同时间发布的帖子保留所有ID。没有可靠顺序或列表覆盖时用已见集合判重并明确覆盖限制。
2. **恢复与重试**：先处理已保存的分页和到期失败项目。暂时网络错误本次最多额外重试一次，之后默认依次隔1小时、6小时、24小时，最多累计5次；用档案配置覆盖。登录/验证码/封禁记录为等待用户或访问条件变化，不循环重试。达到上限保留未解决状态，不删除。
3. **旧文回查**：获取配置窗口内的原条目，比较内容摘要值。正文变化保存新修订；仅指标变化保存指标快照。反馈中明确关联的发布链接也进入回查目标，哪怕超过时间窗口。

仅在正常账号入口和工具可用范围内操作。平台阻止访问时停止该渠道，其他已授权可用来源仍可继续。后台刷新失败不抹掉已有好内容，生成时说明档案最后成功时间及缺口。

## 完整度与学习资格

| 实际取得的内容 | 可以支持的学习 | 不能推断 |
|---|---|---|
| 只有标题和主页卡片 | 标题模式、可见主题 | 全文结构、口播节奏 |
| 完整正文 | 文字语气、篇章结构、结尾 | 未见图片布局、完整视频表达 |
| 部分正文/部分字幕 | 对应片段的局部模式，标partial | 总时长、全篇结构、整体节奏 |
| 原语言完整字幕或校对转写 | 口播措辞、叙述结构 | 没观察到的镜头与表演方式 |
| 实际图片/画面及文字 | 可见视觉和图文关系 | 未获取轮播或镜头的设计 |

每条证据保留来源链接、字段或时间位置及提取方式。登录提示、相关推荐、搜索摘要、广告或观众评论不能混作作者正文。引用内容和本人写作分开标记。

## 范围与完成报告

保存发现、完整、部分、失败、更新和新增数量，注明“最近30条样本”或具体时间范围。平台不知道历史总条数时，不计算全账号百分比覆盖率。

首次汇总后依据 [style-learning.md](style-learning.md) 生成风格档案与历史内容总结。后续仅重新分析新增/变更证据受影响的规则。新历史中若发现能确定关联到已登记创作的发布版本，进入发布后学习；不能唯一关联的只作为本人历史样本，不猜测它改自哪篇草稿。
