# 素材档案与镜头状态

在当前项目交付目录中建立简洁 Markdown 记录，不把项目资料存进 skill 安装目录。仅记录实际用到的信息；先复用已有档案，避免重复登记。

## 素材档案

| 字段 | 内容 |
| --- | --- |
| 稳定编号 | 人物 C01、场景 L01、道具 P01；已有编号优先复用 |
| 名称与版本 | 如「主角日常服 v1」；更换服装可作为明确变体 |
| 文件 | 实际路径与是否已查看；缺失文件明确标记 |
| 参考用途 | 身份、服装、空间、配色、材质或编辑目标 |
| 不可改项 | 用户明确要求或已确认设定；没有确认时标建议 |
| 可变项 | 本镜头允许改变的姿态、表情、机位等 |
| 确认状态 | 用户确认／用户提供但未明确确认／助手建议 |
| 引用镜头 | 使用该版本的镜头编号 |

不把推断的人物身份、职业、年龄或故事设定当作事实。参考图之间不一致时指出冲突；有明确指定主参考就遵循，否则就关键矛盾提问。用于情绪或材质的参考图，不默认覆盖角色身份。

## 逐镜状态

每镜按叙事需要记录：

- 规划起点与终点：角色位置、朝向、视线、动作阶段。
- 道具归属、持握手和所在位置；左右明确是人物自身还是画面方向。
- 服装与外观变体、场景编号、主要光源。
- 与上一镜衔接的状态，以及有意改变的理由。
- 图片/视频中实际观察到的状态与证据版本；未观察到的记待验证。

镜头插入后保留旧编号，可使用 S02A 等新编号；显示顺序单独维护，避免所有图片引用随重排失效。

## 变更传播

更新角色或场景档案时，列出引用旧版本的镜头，标为待复核。确认变更影响可见内容后，才更新对应提示词与示意图。已经满足新要求的图片不重复生成。

只发生机位变化时，人物在画面中的左右位置可能变化。先核对空间与机位，不把所有屏幕位置变化都当作连续性错误。已规划的时间跳跃、地点切换和有意跳切单独标注。
