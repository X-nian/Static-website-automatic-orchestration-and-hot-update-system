部署于 Cloudflare Pages

你好，这是我的演示站点 👋

本站点通过 GitHub 仓库实时推送，自动部署到 Cloudflare Pages。 每次 git push 都会触发一次新的部署。

了解 Cloudflare Pages

实时编辑

在本地修改任意文件，提交并推送后，Cloudflare 会自动拉取并重新部署。

全球 CDN

静态资源由 Cloudflare 全球边缘节点分发，访问速度更快、更稳定。

免费托管

Cloudflare Pages 提供免费的静态站点托管与自动 HTTPS。

工作流

  1. 本地编辑文件（例如这个 index.html）
  2. git add . && git commit -m "update"
  3. git push → 自动触发 Cloudflare Pages 部署
